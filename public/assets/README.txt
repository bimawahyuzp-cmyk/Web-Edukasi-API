PENTING - CARA PASANG GAMBAR:

Semua kode di project ini sudah mengarah ke folder /assets (folder ini),
dengan nama file PERSIS seperti project HTML/CSS kamu sebelumnya, contoh:
  /assets/logo.png
  /assets/bannerjudul.png
  /assets/Card 1.png ... Card 9.png
  /assets/daftargoogle.png
  /assets/facebook.png
  /assets/instagram.png
  /assets/linkedin.png
  /assets/twitter.png
  /assets/kategori.png
  /assets/avatar.png
  /assets/bannercta.png

Yang perlu kamu lakukan:
1. Buka folder "Web Edukasi/assets" dari project HTML/CSS lama kamu.
2. Copy SEMUA file gambar di dalamnya.
3. Paste ke folder "public/assets" di project React ini (folder tempat file
   README ini berada), TIMPA/gabung saja.
4. Hapus file README.txt ini kalau sudah selesai (opsional).

Catatan:
- Beberapa gambar seperti avatar.png dan bannercta.png disebut di kode React
  ini tapi tidak terlihat di screenshot folder kamu sebelumnya - kalau
  belum ada, tinggal tambahkan gambarnya sendiri atau ganti nama file di
  src/pages/Homepage.jsx sesuai yang kamu punya.
- Folder "public" di React itu spesial: semua file di dalamnya diakses
  langsung lewat path "/nama-file", tanpa perlu di-import satu-satu di
  komponen. Makanya nama & lokasi file harus sama persis.
